# 电兵助手：秋招展示与后续验收

## 30 秒介绍

电兵助手是 Java 17 / Spring Boot 的高校校园助手原型。公开规则通过 PDF 解析、分块、PostgreSQL/pgvector 与中文关键词混合检索进入 RAG 问答，返回可追溯原文引用；结构化校园服务经领域层和官方 Java MCP SDK 的只读 Tool 暴露。成绩、课表、考试、课程推荐和学分分析目前使用明确标识的虚构 Mock 数据。

## 可以现场演示的闭环

1. 无 Docker/Ollama 时运行 `./mvnw -Dspring-boot.run.main-class=com.pkb.demo.CampusDemoApplication spring-boot:run`，打开 `/campus.html` 展示虚构学生的课程、成绩、课表、考试安排、学分缺口、选课候选，并输入星期与节次查询按整校周课表推算的空教室。页面调用 `/api/campus/demo` 和 `/api/campus/free-classrooms`，与 MCP 工具共用 `CampusService`。
2. 若有 PostgreSQL 和 Ollama，启动完整应用，在首页导入已核验的官方 PDF；展示索引任务、检索调试、引用卡片和原文跳转。
3. MCP 客户端连接 `http://127.0.0.1:8080/mcp`，列出八个工具，调用 `get_my_grades`、`get_my_exams`、`calculate_my_credit_gap`、`recommend_courses` 和 `find_free_classrooms`。传入任意 `studentId` 会被拒绝；跨站 Origin 会被拒绝。
4. 在首页聊天框提问“我的成绩是多少？”“我的课表周二有什么课？”或“2026-秋周二第3-4节有哪些空教室？”，验证统一入口走确定性 Mock 路由，零 LLM 调用；再问“我的成绩是否满足软件工程学硕毕业学分要求？”，验证虚构数据和真实规则依据分区展示、规则引用及无证据拒答。该组合路径只说明规则，不自动判断毕业资格。
5. 运行 `mvn test`：无数据库环境仍能验证语料切片、领域逻辑和 MCP HTTP 协议。数据库相关测试会明确跳过。

| 统一问答 | 单元测试覆盖纯 Mock 路由、规则加 Mock 组合、无规则证据分支，以及后续公开规则问答的 Mock 历史隔离 | 当前组合仅展示两类依据，不推断个人是否符合真实规则。 |

## 下一阶段按验收条件推进

1. **真实培养方案结构化**：从官方课程表提取课程号、类别、学分及适用范围，逐项人工校对，保留 `note_id/chunk_seq` 引用；用边界样本验证学分缺口。未校对前不得切换计算数据源。
2. **RAG 质量回归**：C119 已补确定性复合问句拆分测试；C128 的依据句已从 PDF 课程表长块中拆出，并在独立库重建索引后进入 Top-5。生成层评测基线同时核对语料指纹、评测集 SHA-256、实际题数和题号；缺失或失效的金标准会使评测失败。C119 完整链路能召回两条证据并在单次生成中写对 14/23 学分，但引用编号仍未逐项支撑；须补引用验证、独立负例、历史版本和不同校区样本，再评估阈值及完整生成正确率。
3. **更多校园工具**：将已在 Mock 数据中实现的先修、名额和课表冲突校验接入真实来源，并处理多教学班、临时调课和实时余量。推荐理由还须关联官方规则来源。考试安排与现有选课建议目前仍为虚构 Mock 数据。
4. **真实接入前安全门槛**：统一身份认证、按登录身份解析 `get_my_*`、工具级授权、跨学生隔离、审计、敏感字段策略及管理员规则发布审核。
5. **部署与可维护性**：CI 已把 Mock 基础测试与 pgvector SQL Repository 测试分作两个作业；首页依赖的 Vue/Marked 已本地化，演示页不依赖公共 CDN。后续仍需备份恢复演练、生产资源缓存策略、数据库迁移工具和带完整语料及模型服务的在线评测环境。
